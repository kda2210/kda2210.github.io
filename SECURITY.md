# Security Policy

This is a small static personal page (one HTML file, no backend, no user data collected). Still, if you find something that looks like a real security issue — for example, a way to inject content into the page, or something that could affect visitors — please **don't open a public issue**.

Email instead: **kda2210@duck.com**

Please include a description of the issue and, if possible, steps to reproduce it. I'll acknowledge your report within a few days.

Things like "this could be minified" or "you could use a bundler" aren't security issues — feel free to raise those as a normal public issue or PR instead.

# Политика безопасности

Это небольшая статическая личная страница (один HTML-файл, без бэкенда, без сбора пользовательских данных). Тем не менее, если вы нашли что-то похожее на настоящую проблему безопасности — например, способ внедрить контент в страницу или что-то, что может повлиять на посетителей — пожалуйста, **не создавайте публичный Issue**.

Вместо этого напишите на почту: **kda2210@duck.com**

Опишите проблему и, если возможно, шаги для воспроизведения. Я подтвержу получение в течение нескольких дней.

Вещи вроде «это можно было бы минифицировать» или «стоило бы использовать сборщик» — не проблемы безопасности, для них подойдёт обычный публичный issue или PR.
