## 🌿 Why these principles matter

I want the software I build to remain accessible to everyone. I follow the same principles across my projects, whatever each application is designed to do.

|  | Principle | In short |
|:---:|---|---|
| 💸 | **Free** | You never pay to use it. |
| 🚫 | **No ads** | Nothing competes for your attention. |
| 🔁 | **No subscriptions** | Install once, use it for as long as you like. |
| 📴 | **Works offline** | Core features work without an internet connection. |
| 🔓 | **Open Source** | Nothing hidden. Read it, verify it, build on it. |

<details>
<summary><b>Read the full reasoning behind each principle</b></summary>

### ✔️ Free

You never have to pay to use my apps. Useful tools should be available regardless of someone's financial situation.

### ✔️ No ads

Ads interrupt the task at hand and make an application less pleasant to use. I prefer software that helps with a task without competing for the user's attention.

### ✔️ No subscriptions

For small personal tools, a subscription often feels unnecessary. I want people to be able to install an app and keep using it without taking on another monthly payment.

### ✔️ Works offline

I design my applications so their core features work without an internet connection. That removes the need for a server, improves privacy, and makes the apps usable in more places. *This page is a small exception: the avatar image is loaded from GitHub. Without a connection it still works, with a placeholder icon instead.*

### ✔️ Open Source from day one

I publish each project as open source from the start. You can inspect the code, see how the application works, check for hidden behaviour, suggest improvements, send fixes (see [Contributing](#en-contributing)), or use the code as a starting point for your own work. The code also remains available if I stop maintaining the project.

</details>

<a name="en-about"></a>
## 📖 About

kda2210.github.io is my personal digital business card. It contains an avatar, a short description, and links for getting in touch. The page is a single static HTML file with no build step, frameworks, or libraries. It also has a few details that take more work than the file size suggests: a soft light that follows the cursor or finger and moves slowly when left alone, a card that reacts to the phone's orientation, and a few smaller touches.

I made the page for my own use. I published it so others can see how it works and use the code as a reference if they find it helpful.

<a name="en-built-with"></a>
## 🛠️ Built with

The page is built with HTML, CSS, and JavaScript, without frameworks or build tools. It uses a few browser APIs directly: the Web Audio API for sound and the Device Orientation API for the gyroscope. The animations use CSS custom properties and `@keyframes`. The page loads no external fonts: it uses the fonts already installed on your device.

```
index.html             — the card itself (this page)
supporters/index.html  — the shared Hall of Supporters page
background.webp        — background image (generated by tools/make_background.py)
tools/                 — the script that generates the background image
docs/                  — screenshots used in this README
LICENSE                — GNU GPL v3 or later (source code)
TRADEMARKS.md          — project name, logo and icon policy
SECURITY.md            — how to report a security issue
CONTRIBUTING.md        — how to contribute and the contribution terms
THIRD_PARTY.md         — origin of the icons and trademark notices
.github/FUNDING.yml    — support links shown by GitHub
.github/PULL_REQUEST_TEMPLATE.md — checklist and consent for pull requests
.github/ISSUE_TEMPLATE/ — templates for reporting problems and ideas
```

<a name="en-fork"></a>
## 🍴 Want to build your own?

The code is open, so you can create your own version. The main things to change are:

- the Telegram / email / VK / phone links
- the avatar (its URL is also used in `<head>`, for the icons and `og:image`) and the background image
- the project name wherever it appears, and the logo and icon (see the [Trademark Policy](TRADEMARKS.md))
- the timezone in the `TIMEZONE` variable, and the city name in the clock tooltip
- the details in the vCard generator
- the meta tags in `<head>` (title, description, Open Graph, canonical) and the JSON-LD block
- the tagline and the text underneath it

## 🏛️ For Organizations & Partners

Everything above is for individuals, and none of it changes here: this project stays 100% free, ad-free, and fully functional for anyone who downloads it. This section doesn't add a paid tier — it just describes a different kind of supporter.

Organizations — companies, foundations, employers, NGOs, schools, research institutions and public bodies — sometimes want to support this work in ways an individual can't, or need to put a project in front of a group of people at once. A few ways that works:

- **Sponsorship credit.** A contribution gets a static "Supported by [name]" line here and on the [Hall of Supporters](https://kda2210.github.io/supporters) — not a banner, not a pop-up, nothing shown inside the app itself.
- **Support agreement.** The project is already free for organizations under the GPL. If you need a written agreement, it can be arranged officially, with a contract and an invoice. It can cover **priority responses** to your questions, **fixes on agreed terms** (priority and timeline), **help with deployment** (installation, configuration, rollout to your people) and **custom changes** made for you. Scope, response times and price are agreed in writing before any work starts, and whether the result is published in the open project is agreed in advance. Each person in your organization still gets the same free, full version, exactly like everyone else.

Yes. An agreement with an organization pays for support, deployment help and custom work — it never turns a feature on or off for anyone. Every individual gets the exact same free, full version whether they found it themselves or got it through an organization.

## 🌿 Почему я придерживаюсь этих принципов

Я хочу, чтобы полезные программы оставались доступными каждому. Поэтому в своих проектах я придерживаюсь нескольких общих правил — независимо от назначения конкретного приложения.

|  | Принцип | Что это значит |
|:---:|---|---|
| 💸 | **Бесплатно** | За использование не нужно платить. |
| 🚫 | **Без рекламы** | Ничто не отвлекает от работы с приложением. |
| 🔁 | **Без подписок** | Установили один раз и пользуетесь сколько угодно. |
| 📴 | **Работа без интернета** | Основные возможности работают без подключения к интернету. |
| 🔓 | **Открытый исходный код** | Код доступен для просмотра, проверки и доработки. |

<details>
<summary><b>Подробнее о каждом принципе</b></summary>

### ✔️ Бесплатно

За использование моих приложений не нужно платить. Я считаю, что полезные инструменты должны быть доступны независимо от финансовых возможностей человека.

### ✔️ Без рекламы

Реклама отвлекает и мешает сосредоточиться. Мне ближе приложения, которые помогают решить задачу и не борются за внимание пользователя.

### ✔️ Без подписок

Для небольших личных инструментов ежемесячная плата кажется мне лишней. Я хочу, чтобы человек мог установить приложение и пользоваться им без ещё одного регулярного платежа.

### ✔️ Работа без интернета

Основные возможности моих приложений работают без подключения к серверу. Страница написана на HTML, CSS и JavaScript — без фреймворков и инструментов сборки. tools/                 — скрипт, который создаёт фоновое изображение
docs/                  — папка со скриншотами для README.md
LICENSE                — GNU GPL версии 3 или более поздней (исходный код)
TRADEMARKS.md          — правила использования названия, логотипа и значка проекта
SECURITY.md            — инструкция по сообщению о проблемах безопасности
CONTRIBUTING.md        — как принять участие и условия участия
THIRD_PARTY.md         — происхождение иконок и уведомления о товарных знаках
.github/FUNDING.yml    — ссылки на поддержку, которые показывает GitHub
