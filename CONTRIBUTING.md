# Contributing

Thank you for wanting to help the project.

## Before you open an issue

1. Check the [README](README.md): the answer may already be in the FAQ.
2. Make sure a similar issue is not already open.

## How to report a problem

Use the issue template. If you can, include:

- the browser and its version,
- the device and operating system,
- the steps to reproduce,
- the expected and the actual behaviour,
- a screenshot.

For security issues, do not open a public issue: follow [SECURITY.md](SECURITY.md).

## Running the page locally

The page is a single static HTML file: open `index.html` in a browser. To test it the way GitHub Pages serves it, start a local server in the project folder, for example `python3 -m http.server`, and open <http://localhost:8000>.

The background image is generated by a script: `python3 tools/make_background.py` (needs `numpy` and `pillow`).

## Principles for changes

Please keep the project's principles: no external requests (the avatar from GitHub is the only exception), no analytics or tracking, no frameworks or libraries, works offline, free for everyone, no ads or subscriptions. Changes that break these principles will not be accepted.

## Pull requests

Before opening a pull request:

1. Make sure the change solves a concrete problem.
2. Check the page in both languages (RU and EN) and on a narrow, phone-sized screen.
3. Update the README if behaviour or settings change.

Small, focused pull requests are reviewed and merged faster. I may decline, rewrite or remove any contribution.

# Участие в разработке

Спасибо за желание помочь проекту.

## Перед созданием issue

1. Проверьте [README](README.md): ответ может быть в разделе FAQ.
2. Убедитесь, что похожий issue ещё не открыт.

## Как сообщать о проблемах

Используйте шаблон issue. По возможности укажите:

- браузер и его версию,
- устройство и операционную систему,
- шаги воспроизведения,
- ожидаемое и фактическое поведение,
- скриншот.

О проблемах безопасности не создавайте публичный issue, а следуйте инструкции из [SECURITY.md](SECURITY.md).

## Локальный запуск

Страница — один статический HTML-файл: откройте `index.html` в браузере. Чтобы проверить её так же, как её отдаёт GitHub Pages, запустите в папке проекта локальный сервер, например `python3 -m http.server`, и откройте <http://localhost:8000>.

Фоновое изображение создаётся скриптом: `python3 tools/make_background.py` (нужны `numpy` и `pillow`).

## Принципы изменений

Сохраняйте принципы проекта: без внешних запросов (единственное исключение — аватар с GitHub), без аналитики и отслеживания, без фреймворков и библиотек, работа без интернета, бесплатно для всех, без рекламы и подписок. Изменения, нарушающие эти принципы, приняты не будут.

## Pull request

Перед открытием pull request:

1. Убедитесь, что изменение решает конкретную проблему.
2. Проверьте страницу на обоих языках (RU и EN) и на узком, телефонном экране.
3. Обновите README, если меняется поведение или настройки.

Небольшие и сфокусированные pull request проверяются и принимаются быстрее. Я могу отказаться принять, переписать или удалить любой вклад.
